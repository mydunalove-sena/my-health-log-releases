## 지원 기기

- Android 7.0 이상
- 현재 버전: **3.18.3 (빌드 60)**
- 아이폰용 설치 파일은 제공하지 않습니다.

## 이미 앱을 사용하고 있다면

1. 기존 앱에서 **홈 → 데이터 관리 → 백업 파일 저장**을 눌러 백업하세요.
2. 기존 앱을 지우지 않고 받은 APK를 열어 **업데이트**하세요.
3. 설치 후 기존 기록과 설정이 보이는지 확인하세요.

백업 파일에는 개인 건강 기록이 들어 있으므로 본인만 보관하세요.

## 이번 버전

- 검사 설정을 ‘검사 항목’과 ‘진료과로 찾기’ 두 탭으로 나눴습니다.
- 검색한 목록의 전체 선택·전체 선택 해제와 ‘체크한 항목만’ 보기를 지원합니다.
- 체크한 검사만 검사 등록 화면에 표시되며, 체크를 해제해도 과거 결과는 남습니다.
